for

for Döngüsü (Sayaçlı Döngü)

Klasik Sayaç

Tekrar sayısı önceden bilindiğinde en çok tercih edilen döngüdür. 3 temel bileşenden oluşur: başlangıç, koşul ve artış/azalış.

📌 Çalışma Sırası (Execution Cycle):
1. int i = 0 (Sadece başlangıçta 1 defa çalışır)
2. i < 5 (Koşul True mu? Değilse döngüden çıkılır)
3. Döngü gövdesi çalıştırılır
4. i++ (Sayaç 1 artırılır, tekrar 2. adıma dönülür)
// 1'den 10'a kadar olan tek sayıları toplayan döngü
int tekToplam = 0;
for (int i = 1; i <= 10; i += 2)
{
    tekToplam += i;
    Console.WriteLine($"i = {i}, Ara Toplam: {tekToplam}");
}
Console.WriteLine($"Sonuç: {tekToplam}"); // 1+3+5+7+9 = 25
while

while Döngüsü (Ön Koşullu)

Durum / Bayrak

Koşul sağlandığı sürece (true oldukça) gövde çalışır. Eğer koşul en başta false ise kod bloğu hiç çalışmaz.

⚠️ Sonsuz Döngü Uyarısı (Infinite Loop):

Gövde içinde koşulu false yapacak artırma/güncelleme adımını unutursanız program kilitlenir!

// Sayı 1 olana kadar 2'ye bölen algoritma
int sayi = 32;
int adim = 0;

while (sayi > 1)
{
    sayi /= 2;
    adim++;
    Console.WriteLine($"Adım {adim}: Kalan Sayı = {sayi}");
}
do

do-while Döngüsü (Son Koşullu)

En Az 1 Kez

Koşul kontrolü bloğun sonunda yapılır. Bu sebeple koşul yanlış bile olsa en az bir kez kesinlikle çalışır. Menü ve kullanıcı girişi doğrulamada vazgeçilmezdir.

💡 Kritik Fark:
Sonda noktalı virgül (while (koşul);) unutulmamalıdır! 
// Kullanıcıdan 1-100 arasında sayı alma simülasyonu
int girilenSayi;
do
{
    Console.Write("1-100 arası sayı giriniz: ");
    girilenSayi = int.Parse(Console.ReadLine()); // En az 1 kez sorar
} while (girilenSayi < 1 || girilenSayi > 100);

Console.WriteLine($"Geçerli sayı kabul edildi: {girilenSayi}");

foreach Döngüsü (Dizi Gezici)

Salt Okunur

Diziler ve koleksiyonlar için özel tasarlanmıştır. Sayaç, indeks veya dizi boyutu ile uğraşmadan her elemana sırayla erişir.

🚫 Mülakat & Sınav Tuzağı (Read-Only Kuralı):

foreach (int sayi in dizi) { sayi = 10; } derleme hatası verir! Dizi elemanlarının değerini güncellemek istiyorsanız mutlaka for döngüsü ve indeks kullanmalısınız. 

string[] diller = { "C#", "JavaScript", "Python", "SQL" };

foreach (string dil in diller)
{
    Console.WriteLine($"Öğrenilen Teknoloji: {dil}");
}

⚡ Döngü Kontrol İfadeleri: break vs continue

Döngünün doğal akışını değiştirmek istediğimizde bu iki anahtar kelimeden yararlanırız.

break (Döngüyü Kır / Çık) Erken Sonlandırma

Döngü koşulu henüz bitmemiş olsa bile döngüyü o anda tamamen terk eder.

// 7 sayısını bulunca döngüyü durdur
for (int i = 1; i <= 10; i++)
{
    if (i == 7) break; // 7'ye gelince döngü biter!
    Console.Write(i + " "); // Çıktı: 1 2 3 4 5 6
}
continue (Bu Turu Atla) Pas Geçme

Altındaki kodları çalıştırmadan hemen bir sonraki döngü adımına zıplar.

// 5 sayısını yazdırmadan atla
for (int i = 1; i <= 7; i++)
{
    if (i == 5) continue; // 5'i yazdırma, sonraki adıma geç!
    Console.Write(i + " "); // Çıktı: 1 2 3 4 6 7
}

En Yaygın Dizi Hatası: IndexOutOfRangeException

Bir dizinin sınırları dışındaki bir indekse erişmeye çalıştığınızda C# çalışma zamanı (Runtime) bu ölümcül hatayı fırlatır ve program anında çöker.

❌ HATALI KOD (ÇÖKER):
int[] notlar = new int[5]; // İndeksler: 0,1,2,3,4
notlar[5] = 100; // ÇÖKTÜ! 5. indeks yoktur!
for(int i = 0; i <= notlar.Length; i++) // <= ÇÖKTÜRÜR!
✅ DOĞRU KOD:
int[] notlar = new int[5];
notlar[4] = 100; // Son eleman [Length - 1]
for(int i = 0; i < notlar.Length; i++) // < ile sınır korunur

Dizi Elemanlarının Toplamı ve Ortalaması

Akümülatör Mantığı

Bir sayaç değişkeni (toplam = 0) açılır, döngüyle her eleman bu değişkene eklenir. Ortalama hesaplanırken tamsayı bölme tuzağına düşmemek için (double) tip dönüşümü (type casting) yapılır. 

int[] notlar = { 65, 80, 45, 90, 70 };
int toplam = 0;

for (int i = 0; i < notlar.Length; i++)
{
    toplam += notlar[i]; // Her elemanı sepete at
}

// DİKKAT: (double) dönüşümü yapılmazsa küsurat kaybolur!
double ortalama = (double)toplam / notlar.Length;

Console.WriteLine($"Toplam: {toplam}");
Console.WriteLine($"Sınıf Ortalaması: {ortalama:F2}"); // 70.00

En Büyük (Max) ve En Küçük (Min) Elemanı & İndeksini Bulma

Referans Kıyaslama

Önemli Püf Nokta: enBuyuk değişkenine 0 DEĞİL, dizinin ilk elemanı olan sayilar[0] değeri atanmalıdır. Aksi halde tüm sayılar negatifse (-10, -5, -20) algoritma hatalı sonuç üretir! 

int[] sayilar = { 42, 17, 89, 5, 63, 89, 21 };

int enBuyuk = sayilar[0];
int enBuyukIndis = 0;

int enKucuk = sayilar[0];
int enKucukIndis = 0;

for (int i = 1; i < sayilar.Length; i++)
{
    if (sayilar[i] > enBuyuk)
    {
        enBuyuk = sayilar[i];
        enBuyukIndis = i;
    }

    if (sayilar[i] < enKucuk)
    {
        enKucuk = sayilar[i];
        enKucukIndis = i;
    }
}

Console.WriteLine($"En Büyük Değer: {enBuyuk} (İndeks: {enBuyukIndis})");
Console.WriteLine($"En Küçük Değer: {enKucuk} (İndeks: {enKucukIndis})");

Doğrusal Arama (Linear Search) & Bayrak (Flag) Mantığı

Var mı / Yok mu?

Kullanıcının girdiği bir elemanın dizide bulunup bulunmadığını kontrol etmek için bir bool bulundu = false; bayrağı açılır. Eleman bulunduğu anda break; ile döngüden çıkılarak gereksiz turların önüne geçilir. 

string[] ogrenciler = { "Ahmet", "Ayşe", "Mehmet", "Fatma", "Zeynep" };
string aranan = "Fatma";

bool bulundu = false;
int bulunanIndis = -1;

for (int i = 0; i < ogrenciler.Length; i++)
{
    if (ogrenciler[i].Equals(aranan, StringComparison.OrdinalIgnoreCase))
    {
        bulundu = true;
        bulunanIndis = i;
        break; // Bulduk! Kalan elemanları boşuna gezme!
    }
}

if (bulundu)
    Console.WriteLine($"✅ {aranan} bulundu! Listedeki sırası (indeks): {bulunanIndis}");
else
    Console.WriteLine($"❌ {aranan} listede bulunamadı.");

Çift ve Tek Sayıları Ayıklama & Filtreleme

Mod (%) Operatörü

sayi % 2 == 0 ifadesi ile sayının çift mi tek mi olduğu saptanır; çift ve tek sayı adetleri ile toplamları ayrı sayaçlarda biriktirilir. 

int[] sayilar = { 14, 25, 36, 47, 58, 69, 70 };
int ciftAdet = 0, tekAdet = 0;
int ciftToplam = 0, tekToplam = 0;

foreach (int s in sayilar)
{
    if (s % 2 == 0)
    {
        ciftAdet++;
        ciftToplam += s;
    }
    else
    {
        tekAdet++;
        tekToplam += s;
    }
}

Console.WriteLine($"Çift Sayılar: {ciftAdet} adet, Toplamları = {ciftToplam}");
Console.WriteLine($"Tek Sayılar : {tekAdet} adet, Toplamları = {tekToplam}");

C# Hazır Array Sınıfı Metotları

.NET Framework / .NET Core içerisinde dizi yönetimini kolaylaştıran statik metotlar.

Array.Sort(dizi)

Sıralama

Dizinin elemanlarını küçükten büyüğe (A'dan Z'ye) artan sırada düzenler. Orijinal diziyi doğrudan değiştirir. 

int[] sayilar = { 50, 10, 40, 20 };
Array.Sort(sayilar);
// sayilar artık: { 10, 20, 40, 50 }

Array.Reverse(dizi)

Ters Çevirme

Diziyi olduğu gibi baştan sona tersine çevirir. (Büyükten küçüğe sıralamak için önce Sort sonra Reverse yapılır). 

string[] harfler = { "A", "B", "C" };
Array.Reverse(harfler);
// harfler artık: { "C", "B", "A" }

Array.IndexOf(dizi, aranan)

İndeks Bulucu

Aranan elemanın ilk karşılaşıldığı indeksi döner. Eğer eleman dizide yoksa kesinlikle -1 döndürür. 

int[] notlar = { 70, 85, 90, 100 };
int sira = Array.IndexOf(notlar, 90);  // 2 döner
int yok  = Array.IndexOf(notlar, 55);  // -1 döner

Array.Clear(dizi, index, adet)

Sıfırlama

Diziyi bellekten silmez! Belirtilen indeksten başlayarak istenilen adette elemanı varsayılan değerine (sayılar için 0, string için null) çeker. 

int[] veriler = { 10, 20, 30, 40, 50 };
// 1. indeksten itibaren 2 elemanı sıfırla:
Array.Clear(veriler, 1, 2);
// veriler: { 10, 0, 0, 40, 50 }

⚖️ Sabit Dizi (T[ ]) ile Dinamik Liste (List<T>) Arasındaki Fark

C# projelerinde ne zaman klasik dizi, ne zaman dinamik koleksiyon tercih edilmelidir?

Klasik Tek Boyutlu Dizi (int[ ])
  • Boyutu sabittir (Tanımlanırken belirtilir).
  • Bellek yönetimi son derece hızlı ve az maliyetlidir.
  • Haftanın günleri, aylar, 10 kişilik sabit grup gibi sayısı net veriler için idealdir.
Dinamik Koleksiyon (List<int>)
  • Boyutu dinamiktir; .Add() ve .Remove() ile esner.
  • Kaç adet eleman geleceği önceden kestirilemeyen senaryolarda (Örn: Veritabanından çekilen ürünler) tercih edilir.

Ortalamadan Büyük Sayıları Ekrana Yazdıran Program

İki geçişli (Two-pass) döngü algoritması
▼

Algoritma Mantığı: Önce 1. döngü ile dizinin tüm elemanları toplanıp aritmetik ortalaması bulunur. Ardından 2. bir döngü kurularak ortalamadan büyük olan elemanlar tek tek ekrana basılır. 

int[] sayilar = { 45, 80, 20, 95, 60, 30, 85 };
int toplam = 0;

// 1. Döngü: Toplamı bul
foreach (int s in sayilar)
{
    toplam += s;
}

double ortalama = (double)toplam / sayilar.Length;
Console.WriteLine($"Sınıf Ortalaması: {ortalama:F2}\n--- Ortalamanın Üstündekiler ---");

// 2. Döngü: Ortalamadan büyükleri filtrele
foreach (int s in sayilar)
{
    if (s > ortalama)
    {
        Console.WriteLine($"-> {s}");
    }
}
Q2

Bir Dizideki En Büyük İkinci Sayıyı Bulma

Klasik teknik mülakat sorusu
▼

İki Farklı Çözüm: 1) Array.Sort() yapıp son elemandan bir öncekini almak. 2) Tek bir for döngüsü ile enBuyuk ve ikinciBuyuk değişkenlerini aynı anda güncellemek (Daha performanslı). 

int[] dizi = { 12, 55, 84, 92, 45, 88 };

int enBuyuk = int.MinValue;
int ikinciBuyuk = int.MinValue;

foreach (int sayi in dizi)
{
    if (sayi > enBuyuk)
    {
        ikinciBuyuk = enBuyuk; // Eski şampiyon ikinci olur
        enBuyuk = sayi;        // Yeni şampiyon atanır
    }
    else if (sayi > ikinciBuyuk && sayi != enBuyuk)
    {
        ikinciBuyuk = sayi;
    }
}

Console.WriteLine($"En Büyük: {enBuyuk}");
Console.WriteLine($"En Büyük İkinci: {ikinciBuyuk}"); // 88
Q3

Hazır Metot Kullanmadan Bir Diziyi Tersten Başka Diziye Kopyalama

Çift sayaçlı for döngüsü pratiği
▼

İpucu: Orijinal dizinin son indeksinden (Length - 1) 0'a doğru geri geri giderken, hedef dizinin 0'ıncı indeksinden başlayıp ileri doğru yazarız. 

int[] orijinal = { 10, 20, 30, 40, 50 };
int[] tersDizi = new int[orijinal.Length];

for (int i = 0; i < orijinal.Length; i++)
{
    // i = 0 iken tersDizi[0] = orijinal[4]
    // i = 1 iken tersDizi[1] = orijinal[3] ...
    tersDizi[i] = orijinal[orijinal.Length - 1 - i];
}

Console.WriteLine("Ters Dizi: " + string.Join(", ", tersDizi)); // 50, 40, 30, 20, 10
Q4

Sayı Tahmin Oyunu (while + Random + Hak Sayacı)

Şartlı döngü ve durum kontrolü
▼

Senaryo: Bilgisayar 1-100 arasında rastgele sayı tutar. Kullanıcının 5 hakkı vardır. Her tahminde "Daha büyük" veya "Daha küçük" diyerek yönlendirir. 

Random rnd = new Random();
int gizliSayi = rnd.Next(1, 101); // 1 ile 100 arası
int hak = 5;
bool bildiMi = false;

Console.WriteLine("1-100 arasında bir sayı tuttum. 5 hakkın var!");

while (hak > 0)
{
    Console.Write($"Kalan Hak: {hak}. Tahmininiz: ");
    int tahmin = int.Parse(Console.ReadLine());

    if (tahmin == gizliSayi)
    {
        Console.WriteLine("🎉 TEBRİKLER! Sayıyı bildiniz!");
        bildiMi = true;
        break;
    }
    else if (tahmin < gizliSayi)
    {
        Console.WriteLine("⬆️ Daha BÜYÜK bir sayı deneyin.");
    }
    else
    {
        Console.WriteLine("⬇️ Daha KÜÇÜK bir sayı deneyin.");
    }
    hak--;
}

if (!bildiMi)
{
    Console.WriteLine($"😢 Haklarınız bitti. Tuttuğum sayı: {gizliSayi}");
}

Q6

Dizideki Tüm Negatif Sayıları Sıfıra Çeviren Kod

Neden foreach değil de for kullanılır?
▼

Dikkat: Dizi elemanını değiştirmek için dizi[i] = 0; yapmamız gerekir. Bu işlem foreach ile yapılamaz; derleyici hata verir. Mutlaka for döngüsü kullanılmalıdır. 

int[] sayilar = { 15, -4, 23, -8, -12, 45, -1 };

for (int i = 0; i < sayilar.Length; i++)
{
    if (sayilar[i] < 0)
    {
        sayilar[i] = 0; // Negatifi sıfırla
    }
}

Console.WriteLine("Düzenlenen Dizi: " + string.Join(", ", sayilar));
// Çıktı: 15, 0, 23, 0, 0, 45, 0

    if (girdi.ToLower() == "cikis")
    {
        break; // Sonsuz döngüden emniyetli çıkış
    }

    if (int.TryParse(girdi, out int girilenSayi))
    {
        genelToplam += girilenSayi;
    }
    else
    {
        Console.WriteLine("Geçersiz giriş! Lütfen sayı yazın.");
    }
}

Console.WriteLine($"Toplam: {genelToplam}");

7. BÖLÜM

Hızlı Hile Sayfası (Cheat Sheet) & Hap Bilgiler

Sınav öncesi son 5 dakikada göz gezdirilecek altın kurallar.

💡 İndeks Kuralı

Diziler 0'dan başlar. N elemanlı dizinin son indeksi N - 1'dir. Döngü koşulunu asla <= dizi.Length yapmayın, daima < dizi.Length kullanın.

💡 Tamsayı Bölme Tuzağı

C#'ta iki tamsayı bölünürse sonuç tamsayı olur (10 / 4 = 2). Ortalamayı doğru (2.5) bulmak için payı (double)toplam / adet şeklinde dönüştürün.

💡 Max / Min Başlangıç Değeri

En büyük veya en küçük sayıyı ararken değişkene kafadan 0 vermeyin! Mutlaka dizinin ilk elemanını (dizi[0]) başlangıç kabul edin.

💡 break vs continue

break döngüyü tamamen öldürür. continue ise sadece o anki turu pas geçip bir sonraki tura zıplatır.

💡 Array.IndexOf Sonucu

Array.IndexOf() aranan elemanı bulamazsa hata vermez; sessizce -1 döndürür. Kontrolü != -1 ile yapın.

💡 Dizi vs Değişken (Heap)

Diziler referans türüdür. int[] b = a; yaptığınızda yeni bir dizi oluşmaz; iki değişken de bellekte aynı hücreleri gösterir!
