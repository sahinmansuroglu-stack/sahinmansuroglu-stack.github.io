CSS Grid: Web Sayfalarını Şekillendirmenin Süper Gücü!

Grid Nedir? Basit Bir Anlatım

Web sayfalarını tasarlarken en zorlandığımız şeylerden biri, elemanları (resimler, yazılar, menüler vb.) istediğimiz gibi ekrana yerleştirmektir. İşte CSS Grid, bu sorunu çözmek için geliştirilmiş harika bir araçtır.

Grid'i, büyük bir kitaplığın rafları gibi düşünebilirsiniz. Kitaplığı önce satırlara ve sütunlara (raflara ve bölmelere) ayırırsınız, sonra da hangi kitabın hangi rafa konulacağını söylersiniz. CSS Grid de tam olarak bunu yapar: Sayfanızı görünmez bir ızgara sistemine böler ve her bir içeriğin bu ızgaranın neresinde duracağını belirlemenizi sağlar.

Örnek 1: Geniş Ekran (Masaüstü) Görünümü

Tipik bir web sitesi düşünelim: Üstte bir başlık, solda menü, menünün yanında ana içerik ve en altta da bir alt bilgi bölümü olsun.

Başlık
Menü
Ana İçerik
Alt Bilgi

Peki bu nasıl yapılır?

display: grid; dedikten sonra en önemli kuralımız grid-template-areas. Bu kural ile sayfa düzenimizin adeta bir haritasını çizeriz. Her bir tırnak içi (" ") bir satırı, içindeki kelimeler ise sütunları temsil eder. 

.kapsayici {
  display: grid;
  grid-template-areas:
    "baslik baslik"
    "menu ana-icerik"
    "alt-bilgi alt-bilgi";

  /* Sütunları da tanımlayalım */
  grid-template-columns: 150px 1fr; /* Menü 150px, ana içerik kalanı kaplasın */
}

/* Hangi alanın neresi olduğunu söylüyoruz */
.header { grid-area: baslik; }
.sidebar { grid-area: menu; }
.main-content { grid-area: ana-icerik; }
.footer { grid-area: alt-bilgi; }
fr Birimi Nedir?: Kodda gördüğünüz 1fr ifadesi "fractional unit" yani "kesirli birim" demektir. Kısacası, "kalan boşluğun payı" anlamına gelir. grid-template-columns: 150px 1fr; kuralı şunları söyler: 'İlk sütun tam olarak 150 piksel olsun. Geriye ne kadar boşluk kalırsa, tamamını (yani 1 payını) ikinci sütuna ver.' Eğer 1fr 1fr deseydik, kalan boşluğu iki eşit parçaya bölerdi.

Dikkat: "baslik baslik" yazdığımızda, "baslik" alanının o satırdaki iki sütunu da kaplamasını söylemiş oluruz. Yan yana farklı isimler ("menu ana-icerik") ise o satırın iki farklı alana bölündüğünü gösterir.

Örnek 2: Dar Ekran (Mobil) Görünümü

Peki ya sayfamıza telefondan bakarsak? Menü ve ana içeriğin yan yana sığması zorlaşır. En iyisi hepsini alt alta dizmektir. İşte burada Medya Sorguları (Media Queries) devreye giriyor! Medya sorguları, "Eğer ekran belirli bir genişlikten darsa, şu CSS kurallarını uygula" demektir.

Başlık
Menü
Ana İçerik
Alt Bilgi

Tek Bir Kural İle Değişim!

CSS dosyamızın en sonuna, sadece dar ekranlar için geçerli olacak yeni bir grid-template-areas haritası çizeriz. 

/* Ekran genişliği 768px veya daha az olduğunda bu çalışsın */
@media (max-width: 768px) {
  .kapsayici {
    grid-template-areas:
      "baslik"
      "menu"
      "ana-icerik"
      "alt-bilgi";

    /* Artık tek sütunumuz var */
    grid-template-columns: 1fr;
  }
}

İpucu: Bu web sayfasının penceresini daraltıp genişleterek canlı örneğin nasıl değiştiğini görebilirsin! İşte bu, duyarlı tasarımın (responsive design) ta kendisi!

Sıra Sende!

Şimdi öğrendiklerini test etme zamanı! Aşağıdaki sorular üzerinde düşünerek Grid mantığını ne kadar anladığını görebilirsin.

Soru 1:

Masaüstü görünümünde menu ile ana-icerik'in yerini nasıl değiştirirsin? Yani menü sağda, ana içerik solda nasıl olur?

Çözümü Gör 💡

Çözüm:

grid-template-areas satırında sütunların sırası değiştirilir ve sütun genişlikleri güncellenir: 
.kapsayici {
  grid-template-areas:
    "baslik baslik"
    "ana-icerik menu"
    "alt-bilgi alt-bilgi";
  grid-template-columns: 1fr 150px; /* Ana içerik solda esnek, menü sağda 150px */
}

Soru 2:

Masaüstü sayfamıza baslik'ın hemen altına, tüm satırı kaplayan bir "Duyurular" (duyuru) alanı eklemek isteseydin, grid-template-areas'i nasıl değiştirirdin?

Çözümü Gör 💡

Çözüm:

"baslik baslik" satırının altına yeni bir "duyuru duyuru" satırı eklenir: 
.kapsayici {
  grid-template-areas:
    "baslik baslik"
    "duyuru duyuru"
    "menu ana-icerik"
    "alt-bilgi alt-bilgi";
}

.duyuru-kutusu {
  grid-area: duyuru;
}

Soru 3:

Sadece mobil görünümde (768px altı) alt-bilgi'yi tamamen gizlemek için medya sorgusunun içine hangi CSS kuralını eklemen gerekir?

Çözümü Gör 💡

Çözüm:

Medya sorgusunun içine alt bilgi sınıfını gizleyen kural yazılır: 
@media (max-width: 768px) {
  .footer {
    display: none;
  }
}

Soru 4:

Masaüstü görünümünü 3 sütunlu yapmak isteseydik (`menu`, `ana-icerik`, `reklam` şeklinde), grid-template-areas ve grid-template-columns nasıl güncellenmeliydi?

Çözümü Gör 💡

Çözüm:

Her satırda 3 sütun tanımlanır: 
.kapsayici {
  grid-template-areas:
    "baslik baslik baslik"
    "menu ana-icerik reklam"
    "alt-bilgi alt-bilgi alt-bilgi";
  grid-template-columns: 150px 1fr 180px;
}

.reklam-alani {
  grid-area: reklam;
}
