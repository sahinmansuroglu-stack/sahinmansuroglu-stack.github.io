CSS Dokümantasyonu 🎨

Bu sayfa, CSS'in temel konularını adım adım ve uygulamalı örneklerle açıklar. Soldaki menüden konular arasında gezinebilirsin.

Çözümlü Örnekler

  1. Yapı Kapsayıcı: Çözüm: <div class="kap"></div> + .kap{max-width:1000px;margin:0 auto;padding:24px}
  2. Renk Değişkeni: Çözüm: :root{--ana:#2563eb} ve color:var(--ana)
  3. Başlık Stili: Çözüm: h2{color:#0f265c;margin:0 0 6px}
  4. Kart: Çözüm: .kutu{border:1px solid #e5e9ef;border-radius:12px;padding:16px}
  5. Buton Hover: Çözüm: .btn:hover{filter:brightness(.95)}

Sıra Sende! (Bölüm 0) 📚

Aşağıdaki HTML yapısını kullanarak dokümantasyonun için bir kap oluştur.

<div id="dok-kap" style="border:1px dashed #ccc; padding:12px">Dokümantasyon alanı</div>
  1. Kutunun arka planını açık gri yap.
  2. Kenarlık köşelerini 8px yuvarla.
  3. Başlığa lacivert bir renk ver.
  4. İç boşluğu 16px yap.
  5. Metni okunur kılmak için satır yüksekliğini artır.

Arka Plan 🏞️

Arka plan rengi, görseli, konumu, tekrarı ve boyutlandırması CSS ile kontrol edilir.

Çözümlü Örnekler

  1. Görsel Ekleme: Çözüm: background-image:url('resimler/bg1.jpg')
  2. Kaplama: Çözüm: background-size:cover ve background-position:center
  3. Tekrar: Çözüm: background-repeat:no-repeat
  4. Gradyan: Çözüm: background-image:linear-gradient(180deg,#3b82f6,#8b5cf6)
  5. Sabit Arka Plan: Çözüm: background-attachment:fixed

Sıra Sende! (Bölüm 3) 🏞️

Aşağıdaki HTML yapısını kullanarak istenen stilleri uygulayın:

<div id="resimli-kutu" style="height: 300px; border: 1px solid white;"></div>
  1. id="resimli-kutu" olan <div> elemanının arka planına 'arkaplan.jpg' adında bir görsel ekleyin.
  2. Görselin yatayda (x ekseninde) tekrar etmesini sağlayın (background-repeat: repeat-x;).
  3. Görselin konumunu sağ alt köşe olarak ayarlayın (background-position: right bottom;).
  4. Görselin kutuya tam sığacak şekilde, en-boy oranını koruyarak boyutlanmasını sağlayın (background-size: contain;).
  5. Maviden mora doğru giden dikey bir doğrusal gradyan arka planı oluşturun.
  6. Arka plan görselinin sayfa ile birlikte kaymamasını, sabit kalmasını sağlayın (background-attachment: fixed;).

Giriş

CSS; renkleri, yazıları, kutuları ve yerleşimi kontrol ederek web sayfalarını güzel ve düzenli yapar.

Çözümlü Örnekler

  2. Arka Plan: Çözüm: body{background:#ffffff}

  4. Kart: Çözüm: .kutu{border:1px solid #e5e9ef;border-radius:12px}
  5. Buton: Çözüm: .btn{background:#2d7ff9;color:#fff}

<div id="giris-kutu" style="border:1px solid #e5e7eb; padding:12px">Hoş geldin!</div>

CSS Nedir?

CSS = Cascading Style Sheets. Yani: “Stil Kuralları”. HTML ile yazdığın şeylerin (yazı, resim, kutu) görünüşünü güzelleştirir.
Unutma: HTML = iskelet ve kelimeler. CSS = renk, boyut, yerleşim.

CSS Nasıl Eklenir?

1) Sayfanın <head> kısmında <style> ile
2) Ayrı bir .css dosyasıyla (<link> kullanılır)
3) Tek etikete style="..." yazarak

Çözümlü Örnekler

  1. Dahili Stil: Çözüm: <style>body{color:#222}</style>
  2. Harici Stil: Çözüm: <link rel="stylesheet" href="stil.css">
  3. Satır İçi: Çözüm: <p style="color:red">Merhaba</p>
  4. Öncelik: Çözüm: inline > dahili > harici (eşitlikte son tanım baskın)
  5. Performans: Çözüm: CSS dosyalarını <head> içinde yüklemek FOUC'u azaltır
Merhaba! Ben bir kutuyum.
(Butona bas ve değişimi gör)

#goster-nasil {
  background: #e6f0ff;
  border: 2px solid #2d7ff9;
  padding: 12px;
  border-radius: 10px;
}

Renkler 🎨

Renkleri isimle (red, blue), kodla (#ff0000) veya RGB ile (rgb(255,0,0)) yazabiliriz.

Çözümlü Örnekler

  1. İsimle: Çözüm: color:red;
  2. Hex ile: Çözüm: background:#3b82f6;
  3. RGB ile: Çözüm: border-color: rgb(34,197,94);
  4. RGBA: Çözüm: background: rgba(0,0,0,.1);
  5. Değişkenle: Çözüm: --tema:#22c55e; color:var(--tema);
Bu kutunun arka plan rengini değiştir.
/* Arka plan rengini değiştir */
#kutu-renk { background: #ffffff; }

/* Örnek: */
#kutu-renk { background: #3b82f6; }

Sıra Sende! (Bölüm 2) 🎨

Aşağıdaki yapıyı kullanarak renkleri dene.

<div id="renk-kutu" style="height:80px; border:1px solid #ddd"></div>
  1. Arka planı kırmızı yapmanın üç farklı yolunu uygula (isim, hex, rgb).
  2. Metin rengini beyaz yap.
  3. Kutunun kenarlığını mor yap.
  4. Köşeleri 12px yuvarla.
  5. Renk paletinden sevdiğin bir tonu seçip uygula.

Metin Biçimlendirme ✍️

Metin boyutu, kalınlık, eğiklik, hizalama ve gölge gibi özelliklerle okuma deneyimi iyileştirilir.

Çözümlü Örnekler

  1. Kalın Yazı: Çözüm: font-weight:700;
  2. Büyük Yazı: Çözüm: font-size:22px;
  3. İtalik: Çözüm: font-style:italic;
  4. Gölge: Çözüm: text-shadow:2px 2px 0 #d1d5db;
  5. Hizalama: Çözüm: text-align:center;
Bu bir başlık!
Bu da normal bir yazı. 
/* Yazı stili örnekleri */
#yazi-alani {
  font-size: 16px;      /* yazı boyutu */
  font-weight: 400;     /* 700 = kalın */
  font-style: normal;   /* italic */
  text-shadow: none;    /* gölge */
}

Sıra Sende! (Bölüm 4) ✍️

Bu HTML ile metni biçimlendir.

<p id="metin">Metin biçimlendirme örneği</p>
  1. Yazıyı kalın yap.
  2. Yazı boyutunu 22px yap.
  3. Satır yüksekliğini 1.6 yap.
  4. Harf aralığını 1px artır.
  5. Metni ortala ve altına hafif gölge ekle.

Kutu Modeli (Box Model) 📦

CSS kutu modeli: içerik → iç boşluk (padding) → kenarlık (border) → dış boşluk (margin)

Çözümlü Örnekler

  1. Padding: Çözüm: padding:12px;
  2. Border: Çözüm: border:2px solid #94a3b8;
  3. Radius: Çözüm: border-radius:10px;
  4. Margin: Çözüm: margin:8px 0;
  5. Box-Sizing: Çözüm: box-sizing:border-box; genişlik hesaplamasını kolaylaştırır.
Ben bir kutuyum. Padding, border ve margin değerlerimi değiştir! 
/* Kutu modeli */
#kutu-model {
  background: #f8fafc;
  padding: 8px;          /* iç boşluk */
  border: 2px solid #94a3b8; /* kenarlık */
  border-radius: 8px;    /* köşe yuvarlama */
  margin: 8px 0;         /* dış boşluk */
}

Sıra Sende! (Bölüm 5) 📦

Kutu modelini uygula.

<div id="kutu" style="border:1px solid #ddd">Kutu</div>
  1. Padding'i 16px yap.
  2. Margin'i üst-alt 12px, sağ-sol 0 yap.
  3. Border'ı 3px ve mavi yap.
  4. Border-radius'u 10px yap.
  5. Kutuyu genişlik olarak 300px yap ve ortala.

Display Özelliği

Öğelerin yerleşim davranışı display ile belirlenir: block, inline, inline-block, flex, grid.

Çözümlü Örnekler

  1. Block: Çözüm: tam satır kaplar, display:block.
  2. Inline: Çözüm: genişlik/height almaz, display:inline.
  3. Inline-Block: Çözüm: satır içi + boyut, display:inline-block.
  4. Flex: Çözüm: tek eksende düzen, display:flex.
  5. Grid: Çözüm: iki eksen düzen, display:grid.

Sıra Sende! (Bölüm 6) 📦

<div id="d-kap">
  <span class="d-og">A</span>
  <span class="d-og">B</span>
  <span class="d-og">C</span>
</div>
  1. .d-og öğelerini inline-block yap ve genişlik ver.
  2. Kap'ı display:flex yapıp öğeleri aralıklı yerleştir.
  3. Kap'ı display:grid yapıp 3 sütun oluştur.
  4. Her modda dikey hizalamayı dene.
  5. Hangi mod hangi durumda uygun? Kısaca yaz.

Flexbox

Esnek kutu düzeni ile tek boyutlu (satır/sütun) hizalama ve dağıtım yapılır.

Çözümlü Örnekler

  1. Başlat: Çözüm: display:flex
  2. Yön: Çözüm: flex-direction:row veya column
  3. Dağıtım: Çözüm: justify-content:space-between
  4. Hizalama: Çözüm: align-items:center
  5. Sarma ve Boşluk: Çözüm: flex-wrap:wrap; gap:12px;

Sıra Sende! (Bölüm 7) 🧭

<div id="flex-kap">
  <div class="el">1</div>
  <div class="el">2</div>
  <div class="el">3</div>
</div>
  1. Kap'a display:flex ver.
  2. Öğeleri yatayda eşit boşlukla dağıt (justify-content: space-between).
  3. Dikeyde ortala (align-items: center).
  4. Sarmayı aç (flex-wrap: wrap) ve boşluk ekle (gap).
  5. Mobilde sütun düzenine geç (flex-direction: column).

Grid

İki boyutlu yerleşim için güçlü bir sistem: satırlar ve sütunlar.

Çözümlü Örnekler

  1. Sütunlar: Çözüm: grid-template-columns:1fr 1fr
  2. Boşluk: Çözüm: gap:12px
  3. Alan Kaplama: Çözüm: .k:nth-child(3){grid-column:1 / span 2}
  4. Satır Yüksekliği: Çözüm: grid-auto-rows:minmax(80px,auto)
  5. Duyarlı: Çözüm: media query ile 1 sütuna düş.

Sıra Sende! (Bölüm 8) 🧩

<div id="grid-kap">
  <div class="k">1</div>
  <div class="k">2</div>
  <div class="k">3</div>
  <div class="k">4</div>
</div>
  1. Kap'a 2 sütunlu grid ver (grid-template-columns: 1fr 1fr).
  2. Satırlar arası ve sütun arası boşluk ekle (gap).
  3. 3. öğeyi 2 sütunu kaplayacak şekilde genişlet.
  4. Küçük ekranda 1 sütuna düş.
  5. Satır yüksekliğini otomatikle ayarla.

Position Özelliği

Öğelerin konumlandırması: static, relative, absolute, fixed, sticky.

Çözümlü Örnekler

  1. Relative: Çözüm: position:relative ile referans oluştur.
  2. Absolute: Çözüm: position:absolute; top:0; right:0;
  3. Fixed: Çözüm: position:fixed; top:0; width:100%;
  4. Sticky: Çözüm: position:sticky; top:16px;
  5. Z-index: Çözüm: z-index:10 ile üstte göster.

Sıra Sende! (Bölüm 9) 📌

<div id="pos-kap" style="height:200px; position:relative; border:1px solid #ddd">
  <div id="kutu-a">A</div>
  <div id="kutu-b">B</div>
</div>
  1. #kutu-a'yı sağ üstte sabitle (position:absolute, top:0; right:0;).
  2. #kutu-b'yi altta sabitle (bottom:0; left:0;).
  3. Sayfaya sabit bir başlık oluştur (position: fixed).
  4. Bir öğeyi position: sticky yap ve yapışmayı dene.
  5. Relative ile absolute farkını not et.

Sözde Sınıflar

Etkileşim ve durumlara göre stiller: :hover, :focus, :active, :first-child, :nth-child() vb.

Çözümlü Örnekler

  1. Hover: Çözüm: button:hover{background:#2563eb}
  2. Focus: Çözüm: input:focus{outline:2px solid #22c55e}
  3. Active: Çözüm: a:active{opacity:.8}
  4. İlk Öğe: Çözüm: li:first-child{font-weight:700}
  5. Seçimli: Çözüm: li:nth-child(odd){background:#f8fafc}

Sıra Sende! (Bölüm 10) 🧪

<button class="ps-btn">Düğme</button>
<ul id="liste">
  <li>Elma</li>
  <li>Armut</li>
  <li>Muz</li>
</ul>
  1. Düğmeye gelince arka planı değiştir (:hover).
  2. Düğme odaklanınca kenarlık rengini değiştir (:focus).
  3. Liste elemanlarının tek sayılılarını renklendir (:nth-child(odd)).
  4. İlk elemanı kalın yap (:first-child).
  5. Tıklanınca kısa süreli efekt ekle (:active).

Geçişler (Transitions)

Geçişler, bir CSS özelliği değiştiğinde yumuşak animasyon sağlar: transition-property, transition-duration, transition-timing-function.

Çözümlü Örnekler

  1. Temel: Çözüm: transition: background 300ms ease;
  2. Birden Fazla: Çözüm: transition: width .3s, border-radius .3s;
  3. Hover Etkisi: Çözüm: .kutu:hover{width:200px}
  4. Zamanlama: Çözüm: transition-timing-function: ease-in-out;
  5. Gecikme: Çözüm: transition-delay: 100ms;

Sıra Sende! (Bölüm 11) 🪄

<div id="tr-kutu" style="width:120px; height:60px; background:#93c5fd"></div>
  1. Kutuya arka plan rengi geçişi ekle (300ms).
  2. Üzerine gelince genişliği 200px olsun.
  3. Köşe yarıçapına da geçiş ekle.
  4. Timing fonksiyonunu ease-in-out yap.
  5. Geçişi birden fazla özelliğe tek satırda tanımla.

Seçiciler (Selector) 🔎

Etiket seçici: p { ... } tüm paragraflar
Sınıf (class): .kirmizi { ... } class'ı olanlar

  2. Sınıf: Çözüm: .kirmizi{color:#ef4444}
  3. ID: Çözüm: #ozel{font-weight:700}
  4. Birleşik: Çözüm: div.kart p{margin:0}
  5. Özellik: Çözüm: a[target="_blank"]{color:#0ea5e9}
