Adım Adım JavaScript Kodlaması ve Mantığı

Öğrencilerinize C# ve Python benzerlikleri üzerinden JavaScript mantığını 4 ana adımda anlatın:

1

HTML Elemanlarına Ulaşmak (document.getElementById)

C#'ta Form üzerindeki bir kutuya txtSayi1.Text ile, Python Tkinter'da entry.get() ile erişiriz. JavaScript'te web sayfasındaki bir etiketi yakalamak için onun ID değerini kullanırız: 

// ID'si 'txtSayi1' olan input etiketini bellek nesnesi olarak yakalar:
let s1Eleman = document.getElementById("txtSayi1");
let s2Eleman = document.getElementById("txtSayi2");

// Kutunun içindeki yazıyı okumak için .value özelliği kullanılır:
let girilenYazi = s1Eleman.value;
💡 Pratik Not: Tek satırda doğrudan değeri de alabiliriz: document.getElementById("txtSayi1").value
2

En Büyük JS Tuzağı: "String Birleştirme (+)" vs "Toplama"

Tüm web tarayıcılarında <input type="number"> olsa bile .value daima String (Metin) tipinde veri getirir! C#'taki Console.ReadLine() ve Python'daki input() fonksiyonlarının daima string getirmesiyle tamamen aynıdır!

❌ HATA: Dönüştürmeden Toplarsak 
let a = document.getElementById("txtSayi1").value; // "5"
let b = document.getElementById("txtSayi2").value; // "3"

let sonuc = a + b;
console.log(sonuc); 
// Sonuç 8 DEĞİL, "53" olur! (Metin birleşti)
✅ DOĞRU: Number() ile Sayıya Çevirmek 
let a = Number(document.getElementById("txtSayi1").value); // 5
let b = Number(document.getElementById("txtSayi2").value); // 3

let sonuc = a + b;
console.log(sonuc); 
// Sonuç: 8 (Gerçek matematiksel toplam!)
🧐 İlginç Soru: "Hocam çıkarma yaparken "10" - "3" yazınca çalışıyor da "10" + "3" neden çalışmıyor?"
Cevap: Çünkü JavaScript'te + operatörü hem matematiksel toplama hem de string birleştirme için kullanılır. Metin görünce hemen birleştirmeyi seçer. Fakat - * / % operatörlerinin metinlerde bir anlamı olmadığı için JavaScript otomatik olarak string'i sayıya dönüştürür (Type Coercion). Ancak iyi bir yazılımcı işini şansa bırakmaz, daima Number() kullanır!
3

5 Aritmetik Operatörün Davranışı

+ Toplama Addition
let s = n1 + n2; İki sayıyı toplar. Number dönüşümü zorunludur!
- Çıkarma Subtraction
let s = n1 - n2; 1. sayıdan 2. sayıyı çıkarır.
* Çarpma Multiply
let s = n1 * n2; İki sayıyı birbiriyle çarpar.
/ Bölme Division
let s = n1 / n2; 7 / 2 = 3.5 (C#'taki gibi 3'e yuvarlamaz!)
% Kalan (Mod) Modulus
let s = n1 % n2; Bölümden kalan sayıyı verir. 14 % 4 = 2
⚠️ Sıfıra Bölme Kuralı: 10 / 0 yaptığınızda C# programı çöker (Exception), Python ise hata verir. JavaScript ise çökmez, Infinity (Sonsuzluk) sonucunu döndürür! Bu yüzden JavaScript'te bölme işleminden önce if (sayi2 === 0) kontrolü yapmak iyi bir alışkanlıktır.

Yöntem 2: Tek Parametreli Profesyonel Fonksiyon Tavsiye Edilen (C# & Python)

Tek bir fonksiyon operatörü parametre olarak alır: onclick="islemYap('+')".

function islemYap(operator) {
  // 1. Kutulardan değerleri oku ve Number() ile sayıya dönüştür
  let s1 = Number(document.getElementById("txtSayi1").value);
  let s2 = Number(document.getElementById("txtSayi2").value);
  let sonuc = 0;

  // 2. Operatöre göre işlemi belirle (C#'taki switch-case)
  switch (operator) {
    case '+':
      sonuc = s1 + s2;
      break;
    case '-':
      sonuc = s1 - s2;
      break;
    case '*':
      sonuc = s1 * s2;
      break;
    case '/':
      if (s2 === 0) {
        alert("Matematikte bir sayı 0'a bölünemez!");
        document.getElementById("lblSonuc").innerText = "Tanımsız";
        return;
      }
      sonuc = s1 / s2;
      break;
    case '%':
      sonuc = s1 % s2;
      break;
  }

  // 3. Sonuçları ekrana yazdır
  document.getElementById("lblIslem").innerText = s1 + " " + operator + " " + s2 + " =";
  document.getElementById("lblSonuc").innerText = sonuc;
}

function temizle() {
  document.getElementById("txtSayi1").value = "";
  document.getElementById("txtSayi2").value = "";
  document.getElementById("lblIslem").innerText = "Temizlendi";
  document.getElementById("lblSonuc").innerText = "0";
}
