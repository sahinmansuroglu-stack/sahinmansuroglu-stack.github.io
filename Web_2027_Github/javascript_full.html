2. Bölüm: Değişkenler, Veri Tipleri ve Operatörler

let, const, Tip Dönüşümleri, Template Literals ve Eşitlik Mantığı

Modern JavaScript'te değişken tanımlamak için let ve const kullanılır. Eski var anahtar kelimesi kapsam (scope) problemleri yüzünden artık tercih edilmez.

🌉

9. Sınıf Python & 10. Sınıf C# Bilgisiyle Köprü Kuralım!

Python & C# ile Karşılaştırma:
• Tip Sistemi: C#'taki gibi int sayi = 10; veya string ad = 'Ali'; şeklinde tip zorunluluğu yoktur. Python gibi dinamik tiplidir (Dynamic Typing). Değişkenin tipi içine atanan değere göre belirlenir.
• Sabitler: C#'taki const double pi = 3.14; ifadesi JS'de const pi = 3.14; olarak kullanılır (Değeri sonradan değiştirilemez).
• Metin Şablonları: Python'daki f-string (f'Ad: {ad}') ve C#'taki ($"Ad: {ad}") karşılığı JS'de Template Literals'dır: Ters tırnak (backtick) ile Ad: ${ad} şeklinde yazılır.
• Eşitlik Farkı: JS'de == sadece değer eşitliğine bakar ('5' == 5 doğrudur), === ise hem türe hem değere bakar (Strict equality: '5' === 5 yanlıştır!). Modern JS'de daima === kullanılır.

Konu Anlatımı ve 5 Kod Örneği

Örnek 1: let, const Kullanımı ve typeof ile Tip Kontrolü

let ile sonradan değiştirilebilen değişkenler, const ile sabitler tanımlanır. typeof operatörü değişkenin türünü söyler.

let puan = 85;               // Number (Tam sayı veya ondalıklı)
const okul = "ATP Meslek Lisesi"; // String (Sabit, değiştirilemez)
let aktifMi = true;          // Boolean (true / false)
let tanimsiz;                // Undefined (Henüz değer atanmamış)
let bosDeger = null;         // Null (Bilinçli olarak boş bırakılmış)

console.log(typeof puan);     // 'number'
console.log(typeof okul);     // 'string'
console.log(typeof aktifMi);  // 'boolean'
console.log(typeof tanimsiz); // 'undefined'

Alt Gr + Virgül (Windows) tuş kombinasyonuyla yapılan ters tırnak (`) işaretiyle metin içine değişkenler doğrudan ${degisken} şeklinde gömülebilir.

Örnek 3: Aritmetik Operatörler ve Sayısal Dönüşüm (Number / parseInt)

prompt() fonksiyonundan dönen tüm değerler varsayılan olarak String'dir. Sayısal işlem yapmadan önce Number() veya parseInt() ile dönüştürülmelidir.

let sayi1 = "25";
let sayi2 = "10";

// Tip dönüşümü yapılmazsa String birleştirme olur:
console.log(sayi1 + sayi2); // Çıktı: "2510" (HATA!)

// Number() ile sayıya dönüştürme:
let n1 = Number(sayi1);
let n2 = Number(sayi2);

console.log("Toplam:", n1 + n2);   // 35
console.log("Fark:", n1 - n2);     // 15
console.log("Çarpım:", n1 * n2);   // 250
console.log("Bölüm:", n1 / n2);    // 2.5
console.log("Kalan (Mod):", n1 % n2); // 5

Örnek 4: Karşılaştırma Operatörleri (== vs ===)

JavaScript'te iki eşitlik operatörü vardır. == otomatik tip dönüşümü yapar, === ise kesin eşitlik arar.

let x = 10;      // Number
let y = "10";    // String

console.log(x == y);   // true  (Çünkü değerleri aynı kabul eder)
console.log(x === y);  // false (Çünkü biri number, diğeri string!)

console.log(x != y);   // false
console.log(x !== y);  // true  (Kesinlikle eşit değil)

console.log(15 > 10);  // true
console.log(10 <= 10); // true

Örnek 5: Mantıksal Operatörler (&&, ||, !)

C#'taki mantıksal operatörlerin aynısıdır: VE (&&), VEYA (||) ve DEĞİL (!).

let yas = 17;
let veliIzni = true;

// && (VE): Her iki şart da true olmalı
let stajaGidebilirMi = (yas >= 16) && veliIzni;
console.log("Staja gidebilir mi:", stajaGidebilirMi); // true

let haftaSonu = false;
let resmiTatil = true;

// || (VEYA): En az biri true ise true
let tatilMi = haftaSonu || resmiTatil;
console.log("Bugün tatil mi:", tatilMi); // true

// ! (DEĞİL): Değeri tersine çevirir
console.log(!tatilMi); // false

3. Bölüm: Koşul Yapıları (if, else if, else, switch-case)

Karar Mekanizmaları, Çoklu Koşullar ve Ternary Operatörü

Programın akışını belirli şartlara göre yönlendirmek için koşul yapıları kullanılır. JavaScript koşul sözdizimi C# diliyle neredeyse tamamen aynıdır.

9. Sınıf Python & 10. Sınıf C# Bilgisiyle Köprü Kuralım!

Python & C# ile Karşılaştırma:
• Sözdizimi: C#'taki if (şart) { ... } else if (şart) { ... } else { ... } yapısının birebir aynısıdır.
• Python'a Göre Fark: Python'daki elif yerine JavaScript'te else if yazılır ve koşullar parantez (...) içine alınmak, kod blokları ise süslü parantez {...} ile kapatılmak zorundadır.

Konu Anlatımı ve 5 Kod Örneği

Örnek 1: Temel if - else ile Ehliyet Yaşı Kontrolü

Belirli bir koşul sağlandığında bir kod bloğu, sağlanmadığında ise else bloğu çalıştırılır.

let yas = 18;

if (yas >= 18) {
    console.log("Ehliyet başvurusu yapabilirsiniz. 🚗");
} else {
    let kalanYil = 18 - yas;
    console.log(`Ehliyet alamazsınız. ${kalanYil} yıl daha beklemelisiniz.`);
}

Örnek 2: if - else if - else ile Karne Notu Derecelendirme

İkiden fazla durumun kontrol edilmesi gerektiğinde else if basamakları kullanılır.

let puan = 78;

if (puan >= 85 && puan <= 100) {
    console.log("Takdir Belgesi almaya hak kazandınız! 🏆");
} else if (puan >= 70 && puan < 85) {
    console.log("Teşekkür Belgesi almaya hak kazandınız! 📜");
} else if (puan >= 50 && puan < 70) {
    console.log("Doğrudan sınıfı geçtiniz. 👍");
} else if (puan >= 0 && puan < 50) {
    console.log("Kaldınız, bütünleme sınavına girmelisiniz. ❌");
} else {
    console.log("Geçersiz puan girdiniz!");
}

Örnek 4: switch - case ile Haftanın Gününü Belirleme

Tek bir değişkenin çok sayıda sabit değere eşitliğini kontrol ederken switch-case kodu daha okunaklı kılar. break unutulmamalıdır.

let gunNo = 3;
let gunAdi;

switch (gunNo) {
    case 1:
        gunAdi = "Pazartesi";
        break;
    case 2:
        gunAdi = "Salı";
        break;
    case 3:
        gunAdi = "Çarşamba";
        break;
    case 4:
        gunAdi = "Perşembe";
        break;
    case 5:
        gunAdi = "Cuma";
        break;
    case 6:
        gunAdi = "Cumartesi";
        break;
    case 7:
        gunAdi = "Pazar";
        break;
    default:
