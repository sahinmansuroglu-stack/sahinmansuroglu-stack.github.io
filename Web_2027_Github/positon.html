CSS Position Özelliği Haritası 🗺️

Kutuları (elemanları) sayfada nasıl konumlandıracağımızı öğrenelim!

Position Nedir?

position özelliği, bir elemanın web sayfasındaki yerleştirme yöntemini belirler. Bu özelliği kullandığımızda, ona top (üst), right (sağ), bottom (alt) ve left (sol) gibi yardımcı özellikler vererek tam olarak nerede duracağını söyleriz.

Bilmen Gerekenler: position özelliğinin 5 ana değeri vardır. Hadi hepsini tek tek inceleyelim!

1. position: static (Varsayılan 🏠)

Bu, tüm HTML elemanlarının varsayılan değeridir. "Statik", "durgun" demektir. Elemanlar sayfaya eklendikleri sırayla (yukarıdan aşağıya, soldan sağa) normal bir şekilde dizilirler. position: static olan bir eleman top, left gibi komutları dinlemez.

Kutu 1 (Statik)
Kutu 2 (Statik)

Gördün mü? Kutu 2'ye top: 50px vermemize rağmen hiç kımıldamadı! Çünkü o "statik".

<div class="kutu">Kutu 1 (Statik)</div>
<div class="kutu" style="position: static; top: 50px;">Kutu 2 (Statik)</div>

2. position: relative (Göreli 🎯)

"Relative", "göreli" demektir. Elemanı normalde olması gereken yere (statik konumuna) göre kaydırmamızı sağlar. En önemli özelliği: Kaydırılsa bile, normal akıştaki eski yerini korumaya devam eder. Diğer elemanlar onun eski yerine göre dizilir. Ayrıca, içindeki absolute elemanlar için bir "ata" (parent) görevi görür!

Kutu 1 (Statik)
Kutu 2 (Relative)
Kutu 3 (Statik)

Dikkat et: Kutu 2, normal yerinden 20px aşağı ve 30px sağa kaydı. Kutu 3 ise Kutu 2'nin *eski* yerinin altına yerleşti.

<div class="kutu">Kutu 1 (Statik)</div>
<div class="kutu relative">Kutu 2 (Relative)</div>
<div class="kutu">Kutu 3 (Statik)</div>
.relative {
  position: relative;
  top: 20px;
  left: 30px;
}

3. position: absolute (Mutlak 🚀)

Bu en ilginç olanıdır! Elemanı normal akıştan tamamen koparır. Artık diğer elemanlar onu görmezden gelir ve onun bıraktığı boşluk kaybolur. absolute bir eleman, kendisine en yakın position değeri static OLMAYAN (yani relative, absolute, fixed veya sticky) atasını (parent) arar ve kendini ona göre hizalar. Eğer böyle bir ata bulamazsa, en son çare olarak sayfanın <body> etiketine göre hizalanır.

Kutu 1 (Statik)
Absolute Kutu
Kutu 2 (Statik)

Bak: "Absolute Kutu", dıştaki yeşil kesikli çizgi olan kapsayıcıya (çünkü o position: relative) göre kendini sağ üst köşeye hizaladı. Kutu 1 ve Kutu 2 ise onu hiç görmeden alt alta dizildi.

<div class="kapsayici">
  <div class="kutu">Kutu 1 (Statik)</div>
  <div class="kutu absolute">Absolute Kutu</div>
  <div class="kutu">Kutu 2 (Statik)</div>
</div>
.kapsayici {
  position: relative; /* Atayı belirliyoruz! */
  border: 2px dashed green;
  height: 200px;
}
.absolute {
  position: absolute;
  top: 10px;
  right: 10px;
}

4. position: fixed (Sabit 📌)

Elemanı ekrana yapıştırır. Sen sayfayı aşağı kaydırsan bile o hep aynı yerde kalır. absolute'den farkı, atasına göre değil, her zaman doğrudan tarayıcı penceresine (viewport) göre kendini hizalamasıdır. Genellikle "sayfanın en üstüne git" butonları veya çerez (cookie) bildirimleri için kullanılır.

Bu kutu normal. Şimdi sayfayı aşağı kaydır...

Ben FIXED'im!
<div class="kutu fixed">Ben FIXED'im!</div>
.fixed {
  position: fixed;
  bottom: 20px;
  right: 20px;
  z-index: 100; /* Diğer şeylerin üstünde kalsın diye */
}

5. position: sticky (Yapışkan 🍯)

Bu, relative ve fixed'in akıllı bir karışımıdır. Eleman, normalde relative gibi davranır, yani akışta durur. Ancak sen sayfayı kaydırıp, eleman tarayıcı penceresinin belli bir noktasına (örneğin top: 0) ulaştığında, orada yapışır ve fixed gibi davranır.

...kaydır...

...kaydır...

Ben STICKY Başlığım!

...kaydırmaya devam et...

...gördün mü nasıl yapıştı?...

...ve şimdi yukarı kaydırınca eski yerine dönüyor...

<h4 class="sticky-baslik">Ben STICKY Başlığım!</h4>
.sticky-baslik {
  position: sticky;
  top: 10px; /* Ekranın üstüne 10px kala yapış */
  background-color: yellow;
}

Çözümlü Örnekler 💡

1. `absolute` ile Elemanı Ortalama

Bir elemanı (kutu) hem dikey hem de yatayda ortalamanın en popüler yolu:

Ortadayım! 
<div class="kapsayici">
  <div class="ortalanmis">Ortadayım!</div>
</div>
.kapsayici {
  position: relative;
}
.ortalanmis {
  position: absolute;
  top: 50%; /* Üstten %50 it */
  left: 50%; /* Soldan %50 it */
  transform: translate(-50%, -50%); /* Kendi boyunun yarısı kadar geri çek */
}

2. `z-index` ile Katman Sırası

position (static hariç) değeri olan elemanlar üst üste binebilir. z-index hangisinin en üstte olacağını belirler. Büyük sayı = en üstte.

Üstte (z-index: 2)
Altta (z-index: 1) 
<div class="onde">Üstte (z-index: 2)</div>
<div class="arkada">Altta (z-index: 1)</div>
.onde {
  position: absolute;
  z-index: 2;
}
.arkada {
  position: absolute;
  z-index: 1;
}

3. Overlay (Kaplama) Efekti

Sayfanın üzerine her şeyi kaplayan yarı şeffaf bir katman eklemek için fixed kullanılır.

Arkada kalan içerik...

Bu bir Overlay Katmanı 
<div class="overlay">...</div>
.overlay {
  position: fixed; /* Veya ata'ya göre 'absolute' */
  top: 0; left: 0;
  width: 100%;
  height: 100%;
  background: rgba(0,0,0,0.5); /* Siyah ama %50 şeffaf */
  z-index: 10;
}

4. `static` vs `relative` Farkı

static elemanlar top/left dinlemez, relative dinler.

static (kımıldamaz)
relative (kayar) 
.static {
  position: static;
  top: 50px; /* BU ÇALIŞMAZ */
}
.relative {
  position: relative;
  top: 10px; /* BU ÇALIŞIR */
}

Görev 1, 2, 3 ve 4: Temel Konumlandırma

İşte relative, fixed, absolute ve z-index kullanımı:

Ben FIXED'im!
Ben Relative'im
Ben Absolute'um
Üstteyim (z: 2)
Alttayım (z: 1)
/* Görev 1: #goreceli'yi 10px aşağı kaydır */
#goreceli {
  position: relative;
  top: 10px;
}
/* Görev 2: #sabit'i sağ üste sabitle */
#sabit {
  position: fixed;
  top: 10px;
  right: 10px;
  z-index: 50; /* Üstte kalması için */
}
/* Görev 3: #mutlak'ı kapsayıcısının sol altına yerleştir */
#kapsayici {
  position: relative; /* Ata (parent) bu olmalı! */
  height: 150px;
  border: 2px solid #10b981;
}
#mutlak {
  position: absolute;
  bottom: 10px;
  left: 10px;
}
/* Görev 4: #ustte elemanını üste çıkar */
.z-index-kapsayici {
  position: relative;
  height: 150px;
}
#ustte, #altta {
  position: absolute;
}
#ustte {
  z-index: 2; /* Yüksek değer */
  top: 10px; left: 10px;
}
#altta {
  z-index: 1; /* Düşük değer */
  top: 40px; left: 40px;
}

Görev 5: Yapışkan Başlık

Aşağı kaydırınca bu başlık (#yapiskan) en üste yapışacak.

Yapışkan Başlık 🍯

/* Görev 5: Başlığı en üste yapışkan yap */
#yapiskan {
  position: sticky;
  top: 0; /* En üste gelince yapış */
  background-color: #f59e0b;
}

Görev 6: Input İçine İkon

Input'u bir kapsayıcıya alıp ikonu absolute ile yerleştirmek:

.input-kapsayici {
  position: relative;
}
.input-ikon {
  position: absolute;
  top: 50%;
  right: 10px;
  transform: translateY(-50%);
}

Görev 7: Bildirim Sayacı

Avatarı kapsayıcıya alıp sayacı absolute ile sağ üstüne atmak:

3 
.bildirim-kapsayici {
  position: relative;
}
.bildirim-sayaci {
  position: absolute;
  top: -5px;  /* Negatif değerle dışarı taşır */
  right: -5px; /* Negatif değerle dışarı taşır */
  background: red;
}

Bu bir 'position: sticky' ve 'bottom: 0' kullanan footer.

  position: sticky;
  bottom: 0;
