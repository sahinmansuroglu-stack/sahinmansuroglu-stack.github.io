CSS Ölçü Birimleri: Web Kutu Boyutları

Web'de bir kutunun boyutunu belirlerken farklı ölçü birimleri kullanılır. Bunlar temelde ikiye ayrılır: **Sabit (Absolute)** ve **Göreceli (Relative)** birimler.

1. px (Pixel) - Sabit Birim

**Tanım:** Ekranda sabit bir noktayı temsil eder. Her zaman aynı boyuttadır.
**Kullanım:** Küçük detaylar ve sabit boyutlar için idealdir. (Ancak responsive tasarımlarda çok önerilmez.)

200px Genişlik, 24px Yazı

Kullanılan Kodlar


<!-- HTML Kodu -->
<div class="birim-kutu px-kutu">200px Genişlik, 24px Yazı</div>

<!-- İlgili CSS Kodu -->
.px-kutu {
    background-color: #ef4444; 
    width: 200px; /* Sabit Genişlik */
    height: 50px;
    font-size: 24px;
}

2. % (Yüzde) - Göreceli Birim

**Tanım:** İçinde bulunduğu ana kutunun boyutuna göre belirlenir.
**Kullanım:** Ana elementin boyutuna bağlı kalmak için kullanılır. (Örn: Bir div'in %50'si)

Ana Kutu (Genişlik: %100)
50% Genişlik

Kullanılan Kodlar


<!-- HTML Kodu -->
<div class="kutu-ortak bg-gray-300">
    Ana Kutu
    <div class="birim-kutu yuzde-kutu">50% Genişlik</div>
</div>

<!-- İlgili CSS Kodu -->
/* Ana kutu (kutu-ortak) genişliği %100 kabul edilir */
.yuzde-kutu {
    background-color: #22c55e;
    width: 50%; /* Ana kutunun %50'si */
    height: 50px;
}

3. em - Göreceli Birim (Kendi Ebeveynine Bağlı)

**Tanım:** Kendi ebeveyn (ana) elementinin **font büyüklüğüne** göre belirlenir.
**Risk:** İç içe geçtikçe değerler katlanarak artabilir.

Ana Kutu Font: 16px
1.5em Font = 24px

Kullanılan Kodlar


<!-- HTML Kodu -->
<div class="em-ana-kutu">
    Ana Kutu Font: 16px
    <div class="birim-kutu em-alt-kutu">1.5em Font</div>
</div>

<!-- İlgili CSS Kodu -->
.em-ana-kutu {
    font-size: 16px; /* 1em buradan hesaplanır */
}
.em-alt-kutu {
    /* Font: Ebeveynin 16px'inin 1.5 katı = 24px */
    font-size: 1.5em; 
    /* Padding: KENDİ fontu (24px) baz alınır! */
    padding: 0.5em; 
    background-color: #0087ff; 
}

4. rem (Root em) - Göreceli Birim (Sayfa Köküne Bağlı)

**Tanım:** Her zaman sayfanın en üstündeki `<html>` elementinin **font büyüklüğüne** göre belirlenir.
**Kullanım:** En popüler ve önerilen göreceli birimdir. İç içe geçse bile katlanmaz. (Varsayılan: 1rem = 16px)

Ana Kutu Font: 16px
1.5rem Font = 24px

Kullanılan Kodlar


<!-- HTML Kodu -->
<div class="em-ana-kutu bg-gray-400">
    Ana Kutu Font: 16px
    <div class="birim-kutu rem-alt-kutu">1.5rem Font</div>
</div>

<!-- İlgili CSS Kodu -->
/* Sayfa kökünde (<html>) varsayılan font 16px'tir. */
.rem-alt-kutu {
    /* Font: Sayfa kökünün 1.5 katı = 24px. Ebeveyne bakmaz. */
    font-size: 1.5rem; 
    /* Padding: Sayfa kökünün 0.5 katı = 8px */
    padding: 0.5rem; 
    background-color: #f97316;
}

5. vw / vh (Viewport Width / Height)

**Tanım:** Tarayıcı ekranının (Viewport) genişlik ve yüksekliğine göre belirlenir.
**Kullanım:** Ekran boyutu değiştiğinde otomatik olarak küçülüp büyüyen (fluid) elementler için kullanılır.

30vw Genişlik, 3vw Yazı

*Tarayıcı penceresinin boyutunu değiştirin. Kutu ve yazı da boyutuyla beraber değişecektir.*

Kullanılan Kodlar


<!-- HTML Kodu -->
<div class="birim-kutu vw-kutu">30vw Genişlik, 3vw Yazı</div>

<!-- İlgili CSS Kodu -->
.vw-kutu {
    background-color: #a855f7;
    /* Genişlik: Ekran genişliğinin %30'u (responsive) */
    width: 30vw; 
    /* Yükseklik: Ekran yüksekliğinin %10'u */
    height: 10vh; 
    /* Font: Ekran genişliğinin %3'ü (ekran küçüldükçe yazı küçülür) */
    font-size: 3vw; 
}

Sıra Sende! (Bölüm 2) 📏

Şimdi öğrendiğin ölçü birimlerini kullanarak aşağıdaki görevleri gerçekleştir. Kendi CSS kurallarını `<style>` bloğuna ekleyebilirsin.

Başlangıç HTML Yapısı:


<div class="gorev-kutu-ana bg-gray-200 p-4">
    <div class="gorev-px bg-red-500">Sabit 150px</div>
    <div class="gorev-yuzde bg-green-500">%75 Genişlik</div>
    <div class="gorev-rem bg-orange-500">1.2rem Yazı</div>
    <div class="gorev-vw bg-purple-500">10vw Yükseklik</div>
</div>

Yapılacaklar (CSS Kuralları):

  • .gorev-px elemanına **width: 150px;** verin.
  • .gorev-yuzde elemanına **width: 75%;** verin.
  • .gorev-rem elemanına **font-size: 1.2rem;** ve **padding: 0.8rem;** verin.
  • .gorev-vw elemanına **height: 10vw;** ve **width: 50vw;** verin. (Tarayıcı boyutunu değiştirerek responsive etkisini gözlemleyin.)
💡 Örnek CSS Çözümünü Gör / Gizle 
.gorev-px {
    width: 150px;
}
.gorev-yuzde {
    width: 75%;
}
.gorev-rem {
    font-size: 1.2rem;
    padding: 0.8rem;
}
.gorev-vw {
    width: 50vw;
    height: 10vw;
}
