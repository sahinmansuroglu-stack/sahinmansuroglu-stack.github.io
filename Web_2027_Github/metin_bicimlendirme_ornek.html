📝 HTML5 Semantik Metin Biçimlendirme

1. <abbr> (Kısaltma):
Dersimizde HTML ve CSS teknolojilerini öğreniyoruz.
2. <bdo> (Bi-Directional Override):
Normal metin: Türkçe soldan sağa.
Ters metin: Bu cümle sağdan sola yazılmıştır.
3. <cite> (Eser / Kaynak):
Bu konu MEB 11. Sınıf Web Tabanlı Uygulama Geliştirme Ders Kitabı içerisinde detaylıca incelenmektedir.
4. <kbd> & <code> (Klavye & Kod):
Kodu kaydetmek için Ctrl + S tuşlarına basın. Konsola yazdırmak için console.log() fonksiyonunu kullanın.
